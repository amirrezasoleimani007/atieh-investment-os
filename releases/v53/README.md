# دیده‌بان مالی — نسخه ۵۳

این سورس از بسته `releases/v52/Atieh52-source.zip` مخزن `atieh-investment-os` استخراج و در بخش دیده‌بان بازطراحی شده است. موتورهای عددی و تجزیه فایل نسخه ۵۲ حفظ شده‌اند.

## اجرا و ساخت

Node.js نسخه ۲۲٫۱۳ یا جدیدتر لازم است.

```sh
npm ci
npm test
npm run build
```

خروجی تک‌فایل، همراه فونت و روایت‌ها، در `dist-standalone/IPS-Dashboard.html` است. خروجی وب چندفایلی در `dist-pages` قرار دارد. برای پیش‌نمایش تک‌فایل، `node scripts/preview-v53.cjs` نشانی محلی `http://127.0.0.1:8773` را سرو می‌کند.

## ساختار تغییرات

- `app/dashboard-app.tsx`: فیلترها، ترتیب نمودار/روایت/جدول، دامنه هم‌ماهیت و بازیابی از دوره بدون داده.
- `app/watch-v53.css`: رابط فشرده، واکنش‌گرا، چاپ و حالت کاهش حرکت.
- `components/scatter-chart.tsx`: مسیر نقطه‌چین رو به جلو، نشانگر متحرک، سال تمام نقاط و راهنمای کوتاه نام/دوره؛ معرفی و فرمول محورها حفظ شده است.
- `components/financial-watch-policy.tsx`: تنها روایت شرکت منتخب بر پایه نسخه چهارم کتابچه.
- `components/watch-status-table.tsx`: جدول محورهای شرکت یا شرکت‌های دامنه انتخابی.
- `lib/watch-narrative.ts`: نگاشت معتبر هشت امتیاز به حالت کتابچه؛ داده ناقص یا نامعتبر حدس زده نمی‌شود.
- `scripts/build-watch-v4.mjs`: کنترل همه ۶٬۵۶۱ حالت و فشرده‌سازی متن‌های تکراری با حفظ شناسه‌ها؛ اصلاح‌های محدود نگارشی در همین فایل ثبت شده‌اند.
- `data/policy/financial_watch_6561_v4_SITE.json`: منبع اصلی کتابچه بدون بازنویسی؛ فایل `watch-v4.runtime.json` خروجی تولیدی است.

## حدود بررسی

کنترل نوع‌ها و ساخت تک‌فایل و وب انجام شد. همه ترکیب‌های کتابچه با شناسه و عنوان منبع تطبیق داده شدند. آزمون‌های رندر کد با داده سالانه موجود و داده ساختگی شش‌ماهه، ترتیب بخش‌ها، سه حالت نمایش، راهنمای محورها، جهت زمانی مسیر و نبود داده را پوشش می‌دهند. آزمون ساختگی، تأیید داده مالی واقعی شش‌ماهه نیست.

صفحه اولیه در ادج باز شد، اما ابزار کنترل مرورگر هنگام بارگذاری فایل به دلیل تشخیص نامطمئن نشانی فعال متوقف شد. بازبینی بصری نهایی و آزمون اشاره‌گر و حرکت در مرورگر کامل نشده‌اند. آزمون رندر کد جایگزین این بررسی بصری نیست.

چهار آزمون قدیمی نیازمند فایل اختصاصی شش‌ماهه، در اجرای عادی بدون آن فایل کنار گذاشته می‌شوند. متغیر `IPS_INTERIM_WORKBOOK` باید به همان فایل مورد انتظار نسخه ۵۲ اشاره کند؛ فایل قدیمی سالانه برای آن مناسب نیست. برای آزمون رندر با داده واقعی سالانه، `IPS_ANNUAL_WORKBOOK` را تنظیم کنید؛ در نبود فایل، داده ساختگی شفاف استفاده می‌شود.

داده‌های مالی کاربر در بسته یا سایت منتشر نشده‌اند. فایل‌های منبع کتابچه قبلی برای سازگاری آزمون‌های قدیمی باقی مانده‌اند و در روایت دیده‌بان جدید استفاده نمی‌شوند.
