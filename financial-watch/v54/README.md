اسکریپت `scripts/build-watch-v7.mjs` نسخه فشرده runtime را تولید می‌کند. تکرار متن‌ها در حافظه حذف می‌شود، اما محتوای هر عنوان و پاراگراف با منبع دقیقاً برابر می‌ماند.
