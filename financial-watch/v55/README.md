## استفاده بدون حساب و کلید

پس از ورود داده و انتخاب شرکت در دیده‌بان، بخش «گزارش چندبعدی عملکرد شرکت» را در پایین صفحه باز کنید و «ساخت گزارش نمونه» را بزنید. نمونه چهار بند دارد: وضعیت دوره، تغییرات، مقایسه با همتایان و موضوع بررسی. این خروجی قاعده‌محور و محلی است؛ خروجی هوش مصنوعی نیست. هیچ داده مالی نمونه‌ای در بسته انتشار قرار نگرفته است.

پیش‌فرض گزارش، آخرین دوره موجود همان شرکت است؛ امکان استفاده از دوره انتخابی صفحه هم وجود دارد. تاریخ ورود فایل از دوره مالی جدا نمایش داده می‌شود. مقایسه با دوره مشابه سال قبل، در همان خانواده سالانه یا شش‌ماهه انجام می‌شود. داده مفقود با صفر یا مقدار دوره دیگر پر نمی‌شود. نمودار هشت‌محوری، دوره گزارش، مشابه قبل و میانه سایر همتایان را در مقیاس ثابت صفر تا ده نشان می‌دهد.

همتایان از شرکت‌های همان مدل/گروه بارگذاری‌شده، با ماهیت و دوره یکسان انتخاب می‌شوند. شرکت مورد بررسی از مرجع حذف می‌شود؛ میانه هر محور حداقل به دو شرکت دیگر با داده معتبر نیاز دارد. تعداد معتبر هر محور در بسته شواهد مشخص است. رتبه موجود از وزن‌های پایه سامانه استفاده می‌کند. تولید، فروش محصول و بودجه هنوز به بسته گزارش جدید متصل نشده‌اند.

## اجرای محلی و آماده‌سازی اتصال واقعی

Node.js نسخه 22.13 یا جدیدتر لازم است. سورس را استخراج و در پوشه آن اجرا کنید:

```powershell
npm ci
npm test
npm run build
npm run report:serve
```

سپس `http://127.0.0.1:4178` را باز کنید. بدون کلید، حالت نمونه فعال می‌ماند. GitHub Pages صرفاً نسخه نمایشی است و امکان نگهداری کلید یا اجرای سرور ندارد.

پس از ساخت حساب و کلید در OpenRouter، فایل `OPENROUTER.example.env` را به `.env.openrouter.local` کپی کنید. کلید را فقط در این فایل محلی و متغیر `OPENROUTER_API_KEY` قرار دهید؛ در گفتگو، کد مرورگر یا GitHub وارد نکنید. نام ثابت مدل را در `OPENROUTER_MODEL` با قالب `provider/model:free` بگذارید. مدل و ارائه‌دهنده باید خروجی ساختاریافته JSON Schema و سیاست درخواست را پشتیبانی کنند. سرور را دوباره اجرا کنید.

اتصال زنده تنها پس از تشخیص تنظیمات سرور و تیک رضایت ارسال بسته شواهد از داخل صفحه فعال می‌شود. نام شرکت، نام فایل و ردیف‌های خام ارسال نمی‌شوند، ولی بسته همچنان شامل اطلاعات مالی و امتیازهای شرکت است. در این تحویل هیچ درخواست واقعی تحلیل به OpenRouter ارسال نشده؛ آزمون رابط با پاسخ‌های شبیه‌سازی‌شده انجام شده است.

درخواست به مدل رایگان ثابت محدود است؛ تغییر خودکار به مدل پولی یا تلاش مجدد خودکار ندارد. سقف قیمت صفر، منع جمع‌آوری داده نزد ارائه‌دهنده و الزام پشتیبانی پارامترها در درخواست تعیین شده‌اند. نبود ارائه‌دهنده سازگار یا اتمام سهمیه، خطای کنترل‌شده می‌دهد. این تنظیم به معنای تضمین نگهداری‌نشدن داده نزد تمام واسطه‌ها نیست؛ سیاست سرویس انتخابی را پیش از ارسال بررسی کنید.

این سرور پایلوت فقط روی loopback اجرا می‌شود، یک درخواست هم‌زمان و سقف چهل فراخوانی در هر بار اجرای سرور دارد. برای استقرار عمومی چندکاربره، احراز هویت، محدودسازی کاربر و مدیریت امن اسرار باید اضافه شود.

## کنترل خروجی و محدودیت تحلیل

محاسبات، دوره‌ها و مرجع همتایان در کد انجام می‌شوند. مدل فقط بسته شواهد را می‌گیرد و چهار بند JSON برمی‌گرداند. شناسه شواهد، قالب، ترتیب بندها و ارجاع اعداد کنترل می‌شوند؛ اعداد از مقادیر محاسبه‌شده جای‌گذاری می‌شوند. HTML و اعداد مستقل مدل پذیرفته نمی‌شوند. این کنترل‌ها صحت معنایی همه جملات را تضمین نمی‌کنند؛ گزارش هوش مصنوعی پیش‌نویس قابل بازبینی است.

## اعتبارسنجی این انتشار

۶۴ آزمون موفق، چهار آزمون قدیمی فاقد فایل واقعی شش‌ماهه کنارگذاشته‌شده، بررسی TypeScript و ساخت مستقل و Pages موفق. تطابق دقیق تمام ۶۵۶۱ حالت کتابچه هفتم حفظ شده است. بازبینی محلی در Edge شامل آخرین دوره شرکت، تغییر به دوره انتخابی، پاک‌شدن گزارش قدیمی، نمودار و چهار بند گزارش نمونه بوده است. اتصال بدون کلید غیرفعال و آزمون‌های رابط OpenRouter شبیه‌سازی‌شده‌اند؛ کیفیت پاسخ یک مدل واقعی هنوز سنجیده نشده است.
