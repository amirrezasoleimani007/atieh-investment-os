# بازبینی مسیر حرکت، نسخه ۲۶

## تغییرات مؤثر بر تصمیم

1. نمای نخست تحلیل ISIC اکنون تمام ۲۸ بخش مادر را نشان می‌دهد: ۲۴ بخش با داده ۴ رقمی، سه بخش تجمیعی ۳ رقمی و یک بخش بدون امتیاز. رتبه و تغییر رتبهٔ بخش مادر نسبت به وزن متوازن محاسبه و در سطح مشابه مقایسه می‌شود.
2. شرط حداقل ۷۰٪ پوشش وزن در کنار حداقل چهار شاخص معتبر اعمال می‌شود. در سناریوی رشد‌محور، پنج فعالیت با پوشش ناکافی دیگر امتیاز و رتبه نمی‌گیرند؛ مقدار Missing صفر نشده و جمعیت صدک ثابت می‌ماند.
3. فعالیت ۱۹۲۰، با داده عددی معتبر و نگاشت چندگانه، در رتبه مستقل فعالیت‌ها قرار دارد؛ وارد میانهٔ هیچ بخش مادری نمی‌شود.
4. پیشنهاد Focus و تصمیم مدیر جدا ذخیره می‌شوند. سال‌های پرتفوی وضعیت «پیش‌فرض»، «در حال تدوین» و «ثبت‌شده» دارند. تأیید بعد از توازن سهم و تخصیص ممکن است؛ ویرایش یا خروج یک فرصت تخصیص‌یافته از مأموریت، تأیید سال متأثر را لغو می‌کند.
5. طبقهٔ پیشنهادی ۱۱ دارایی فعلی قابل اصلاح و تأیید ردیفی است. نام‌های نزدیک با ارزش و سهم یکسان حذف نشده‌اند و شکاف فعلی تا تأیید معنای طبقه‌بندی، موقت است.
6. خروجی سیاست JSON نسخه ۲ دارای نام سناریو، نسخه مدل، Snapshot، دوره Master Data، وزن فعال و وضعیت ثبت است. ورود JSON نسخه ۱ پشتیبانی می‌شود.

## نتایج و محدودیت داده

نگاشت ستون‌ها، منطق میانه و روش داده ناقص در [مستند روش](movement-path-method.md) ثبت شده‌اند. منبع ۱۴۵ فعالیت دارد؛ دوره غالب ۲۰۱۵ تا ۲۰۲۱ است. آستانه ۷۰٪ یک فرض اجرایی قابل بازنگری است. دو ردیف نزدیک «آتیه صنعت افق نقش جهان» در دادهٔ پرتفوی ماهیت مستقل/تکراری اثبات‌شده ندارند و برای تصمیم‌گیری نهایی باید مالک داده آن‌ها را تعیین تکلیف کند.

نسخه عمومی داده‌های `public/data` را بدون کنترل دسترسی ارائه می‌کند و برای داده محرمانه عملیاتی مناسب نیست. همگام‌سازی تصمیم‌ها بین کاربران/دستگاه‌ها در این نسخه وجود ندارد.

## کنترل فنی

`npm test` ساخت تولید و ۳۷ آزمون را اجرا می‌کند. `npm run lint` و `npx tsc --noEmit` کنترل ساختاری و نوعی را انجام می‌دهند. پاسخ HTTP مسیر اصلی در حالت Production کنترل شده است.
