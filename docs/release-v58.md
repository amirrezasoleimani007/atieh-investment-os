# نسخه ۵۸ — بازطراحی مسیر حرکت

- ذخیره پیش‌نویس از گام‌های مسیر حرکت؛ ذخیره مرحله، سال و نمای نقشه برای هر سناریو. ورود فایل به‌صورت مستقل یا جایگزینی و پشتیبان کامل حفظ شده‌اند.
- ثبت نسخه تاریخ‌دار مستقل از تأیید مرحله؛ گزارش CSV از انتخاب‌های ثبت‌شده با نام سناریو، بازبینی و زمان ثبت. بازکردن نسخه تاریخ‌دار، یک پیش‌نویس مستقل با ورودی‌های ثبت‌شده می‌سازد و گزارش اصلی ثابت می‌ماند. اگر داده مرجع تغییر کرده باشد، محاسبه پیش‌نویس از داده جاری استفاده می‌کند.
- کارت تصمیم: همان خانه و آستانه‌های ماتریس رشد، وضعیت مأموریت و شروط، سهم و وزن مؤثر مؤلفه‌ها، دامنه حساسیت امتیاز به جابه‌جایی پنج واحد درصد وزن.
- نزدیکی به بازرگانی فولاد: مستقل از فرمول اولویت؛ برای زیربخش، مقدار حوزه مادر. انتخاب برای بررسی بدون الزام به انتخاب نوع ورود. ثبت اختیاری هدف، سازوکار، سطح تعهد، قدم اول، شرط پیشروی، جایگزین و دلیل ترتیب مدیریت.
- فایل JSON برای بازیابی و CSV برای مطالعه و ارائه است. فایل تک‌سناریو ارزیابی‌ها و مصوبات تخصیص سرمایه را به‌طور کامل پوشش نمی‌دهد؛ برای آنها پشتیبان کامل بگیرید.
- اجرا: ZIP نسخه اجرایی را باز کنید، در پوشه والدِ `atieh-investment-os` دستور `python -m http.server 8000` را اجرا کنید و نشانی `http://localhost:8000/atieh-investment-os/` را باز کنید. از فایل HTML مستقیم استفاده نکنید. برای ساخت از سورس: `npm ci` و سپس `npm run build:github-pages`.
