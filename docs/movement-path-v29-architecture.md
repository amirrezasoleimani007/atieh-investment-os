# معماری مسیر حرکت نسخه ۲۹

## مسیر تصمیم

نسخه ۲۹ بدون تغییر موتورهای علمی فرصت، تناسب راهبردی و تحلیل تفصیلی، تصمیم را در چهار گام پیوسته سازمان می‌دهد:

1. **جهت‌گیری راهبردی پرتفوی:** تنظیم سهم هسته/مجاور/تحولی و غربال مأموریتی ۷۷ حوزه.
2. **ارزیابی تفصیلی فرصت‌ها:** رتبه‌بندی فعالیت‌های ۳ و ۴ رقمی با شش شاخص موجود و مدیریت داده مفقود.
3. **اولویت‌های راهبردی و برنامه ورود:** ثبت نظر مستقل مدیریت و انتخاب فرصت‌های هر سال ۱۴۰۶ تا ۱۴۱۴.
4. **تخصیص راهبردی سرمایه و منابع:** اتصال برنامه ورود به ظرفیت مالی، آزادسازی سرمایه و پرونده اجرایی.

## تعریف امتیازها

| عنوان رابط | تعریف | اثر در مدل علمی |
|---|---|---|
| امتیاز فرصت | مختصات فرصت مدل ۷۷ بخشی | مستقل از پرتفوی |
| تناسب راهبردی | مختصات هم‌راستایی با ترکیب هسته/مجاور/تحولی | با سیاست پرتفوی بازمحاسبه می‌شود |
| امتیاز حوزه در مدل ۷۷ بخشی | امتیاز ترکیبی موجودِ فرصت و تناسب | شامل تحلیل تفصیلی نیست |
| امتیاز تفصیلی | حاصل شش شاخص فعالیت‌های تفصیلی | با امتیاز حوزه ادغام نمی‌شود |
| اولویت مدیریت | قضاوت مستقل ۱ تا ۵ یا «بدون نظر» | امتیازهای علمی را تغییر نمی‌دهد |
| اولویت ورود | شاخص اجرایی برای مرتب‌سازی برنامه ورود | وزن پایه ۵۰/۳۰/۲۰؛ داده مفقود صفر نیست |

## الگوریتم تخصیص

1. منبع اختصاصی معتبر، در صورت وجود، پیش از آبشار عمومی تخصیص می‌یابد.
2. آبشار منبع بر اساس نوع نیاز اجرا می‌شود.
3. بدهی‌ای که نرخ آن از سقف مجاز پرونده بیشتر باشد قابل تخصیص نیست.
4. سقف کل بدهی جدید به‌طور هم‌زمان برای بدهی کوتاه‌مدت و میان/بلندمدت کنترل می‌شود.
5. اگر پرونده مرحله‌پذیر به حداقل اجرای خود نرسد، تمام تخصیص موقت آن آزاد می‌شود.
6. موازنه هر پرونده، ظرفیت هر منبع و کل منابع بازمحاسبه و کنترل می‌شود.

### آبشارها

| نوع نیاز | ترتیب تخصیص |
|---|---|
| سرمایه در گردش | بدهی کوتاه‌مدت ← منابع داخلی ← بدهی میان/بلندمدت ← شریک |
| نگهداشت / نوسازی / الزامات | منابع داخلی ← بدهی میان/بلندمدت ← واگذاری قابل اتکا ← شریک |
| توسعه / سرمایه‌گذاری ثابت رشد | بدهی میان/بلندمدت ← منابع داخلی ← شریک ← واگذاری قابل اتکا |
| تملک / سرمایه‌گذاری راهبردی | شریک ← منابع داخلی ← بدهی میان/بلندمدت ← واگذاری قابل اتکا |
| تقویت ساختار مالی | منابع داخلی ← واگذاری قابل اتکا ← شریک ← بدهی میان/بلندمدت |
| سرمایه‌گذاری مالی / پرتفویی | منابع داخلی ← شریک ← واگذاری قابل اتکا ← بدهی میان/بلندمدت |

این جدول در نسخه ۳۱ با ثابت `SOURCE_WATERFALL` موتور موجود تطبیق داده شد؛ ترتیب محاسباتی تغییر نکرده است. منبع اختصاصی معتبر قبل از چهار مرحله عمومی قرار دارد. نرخ، سقف بدهی مشترک، حداقل اجرا و برگشت تخصیص ناموفق در همان موتور کنترل می‌شوند.

## آزمون‌های پذیرش

- سناریوی ۱۴۰۶ مرجع: نیاز و اجرای ۱۷۰۰، منابع داخلی ۴۰۰، بدهی کوتاه‌مدت ۶۰۰، بدهی بلندمدت ۳۰۰ و شریک ۴۰۰.
- حذف بدهی گران‌تر از سقف نرخ پرونده.
- آزادسازی تخصیص موقت در صورت عدم تحقق حداقل اجرا.
- عدم ورود واگذاری صرفاً برنامه‌ریزی‌شده به ظرفیت.
- تطبیق جمع نیاز، اجرای پرونده‌ها، مصرف منابع و سقف بدهی.

آزمون‌های خودکار در `tests/capital-allocation-v13.test.mjs` قرار دارند.
